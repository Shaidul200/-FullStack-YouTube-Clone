# Full-Stack YouTube Clone

A full-stack YouTube-inspired web application built to demonstrate my skills in frontend and backend web development. The project includes a responsive user interface and a REST API that supports authentication, video management, and social interaction features.

## Features

- **User Authetiontican:** User registration, login, and JWT-based authentication.
- **Video Management:** Create, manage, and organize video content.
- **Likes and Comments:** Interact with videos through likes and comments.
- **Subscriptions:** Subscribe to channels and manage subscriptions.
- **Playlists:** Organize videos into playlists.
- **Tweets:** Share short text-based posts.
- **Channel Dashboard:** Manage channel-related content and information.

## Tech Stack

**Frontend**

- React.js
- Tailwind CSS

**Backend**

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Tokens (JWT)
- Cloudinary for media management

## Project Structure

- `frontend/` — React application and user interface.
- `backend/` — Express REST API, authentication, database models, and application logic.

## Purpose

I built this project to strengthen my full-stack development skills and apply my knowledge of React, REST API design, authentication, database management, and media handling in a practical application.

This project is inspired by YouTube and is intended for learning and portfolio purposes.
